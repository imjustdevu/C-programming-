## 💻 How to Run the Code Locally

To compile and run any of the `.c` files in this workspace, open your terminal inside the folder and run:

```bash
# 1. Compile the code (replaces 'filename' with your file)
gcc filename.c -o program

# 2. Run the compiled application
./program
```
